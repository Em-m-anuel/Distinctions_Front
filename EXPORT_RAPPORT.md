## Reprise : maquette uniquement

Le HTML contient le contenu affiché, sans écran de chargement dépendant de Laravel. Aucun moteur applicatif, magasin CF/GO, session, API ou règle de transition métier livré. Seul assets/js/maquette.js anime la présentation ; data/demo-<famille>-<page>.js contient des fragments HTML de démonstration pré-rendus. Les menus et tiroirs de consultation sont conservés. La page Dossiers propose Vue actuelle / Vue nouvelle (nouvelle par défaut), avec liste, sélection, cinq onglets et tiroirs de la vue actuelle. Les actions métier restent indisponibles, jamais simulées. Une CSP interdit réseau et soumission. Le menu mobile conserve les classes du panneau source et est monté hors du header pour éviter le contenant créé par backdrop-filter. Les compteurs sont figés à leur valeur finale, sans animation.

Fabrication : le formulaire Service/new-dossier est présenté depuis le rendu existant, sans appliquer une autorisation réelle. Le défaut de portée remEffective de views-dossiers.js est compensé uniquement dans la copie temporaire utilisée pour rendre les tiroirs ; le script applicatif original reste inchangé et cette copie est ensuite supprimée. Ce point n’est pas une correction de l’application. Le dernier segment incomplet des vagues SVG de public/js/views/home.js:130 est écarté uniquement dans les instantanés : les segments valides déjà dessinés par le navigateur sont conservés, sans inventer de tracé ni modifier la source.
